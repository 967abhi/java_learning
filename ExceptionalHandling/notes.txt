What is Exception Handling?
-> This is a mechanism that is used to handle the exception that occurs during the program of the execution
main()->method a()->method b() so it come in the stack and java is LIFO -> last in first out 
so what java do suppose that if the code is written on the b() method and then the issues came the Arithmatic Exception so then it show the A() method and told to check that A() method have the exception or not 

-> if A() method don't have the exception so it show the main() method and told to check that main() method have the exception or not 
->So if main will not take care then it will return the error or print into the console -> Default Exception Handling 


-> if main will take care of the exception then it will not print the error or it will not print into the console -> it is called the user defined Exception Handling
Stack Trace:- 
-> This is a process of showing the exception that occurs during the program of the execution
-> It is a sequence of method calls that are made during the program of the execution


Syntax of Exception Handling:- 
try {
    // code that may throw an exception
} catch (ExceptionType e) {
    // code to handle the exception
}

Example:- 
try {
    int a = 5;
    int b = 0;
    System.out.println(a / b);
} catch (ArithmeticException e) {
    System.out.println(e.getMessage());
}
