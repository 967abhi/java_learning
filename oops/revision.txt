ONE-LINE RECALL - if I remember only these, I am fine
---------------------------------------------------------
CLASS       = blueprint (not real).  OBJECT = the real entity from it.
              reference in STACK, object in HEAP, "new" allocates heap.
CONSTRUCTOR = same name as class, NO return type, runs on "new".
              overloading = different parameter list.
              chaining    = this(...) / super(...) as the FIRST line.
this        = the current object. Used when parameter name == field name.
CALL BY VALUE = always a copy. For objects the REFERENCE is copied, so
              field changes DO show outside, but reassigning does not.
STATIC      = belongs to the class, one shared copy, accessed by class
              name, cannot use "this", static block runs once at load.
PACKAGE     = folder of related classes, avoids name conflict.
ENCAPSULATION = private data + public getter/setter (data hiding).
              the real benefit is VALIDATION inside the setter.
              getter only -> read only. setter only -> write only.
ACCESS      private < default(package) < protected < public
INHERITANCE = extends, code reuse. single / multilevel / hierarchical.
              multiple NOT allowed for classes (diamond) -> interfaces.
              super.field, super.method(), super(...) first line.
OVERLOADING = same class, different params  -> COMPILE time polymorphism
OVERRIDING  = parent-child, same signature  -> RUNTIME polymorphism
ABSTRACTION = hide implementation. abstract class (0-100%) or
              interface (100%). abstract class cannot be instantiated,
              child MUST override every abstract method.
INTERFACE   = implements, methods public by default, variables are
              public static final, no constructor, many can be
              implemented -> Java's multiple inheritance.
4 PILLARS   = Encapsulation, Inheritance, Abstraction, Polymorphism.

---------------------------------------------------------
UPCASTING - the line to remember
---------------------------------------------------------
    Car c1 = new FuelCar();     // parent reference, child object
    c1.accelerate();            // runs FuelCar's version -> runtime
                                //   polymorphism / dynamic dispatch
  Reference type decides WHAT I can call.
  Object type decides WHICH version runs.
